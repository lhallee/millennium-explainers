# Lean reader 1: the assembly and the analytic endgame

Region: from `Main` down to the zero-free statement `Formalism.HC.ZeroFreeAll`, and the interface that the
zero-free statement needs from the rest of the tree. Tree read: `sources/riemann/lean/lean/src/`, read on
2026-11-21 with the index in `.cache/lean-index/`. All paths below are relative to that `src` folder. Lean
blocks are verbatim; everything else is my reading, and where a sentence is an interpretation and not a
restatement it says so.

Notation used in this digest. $\Lambda$ is the von Mangoldt function, $\gamma$ is Euler's constant, $(t)_+ =
\max(t,0)$, $L(s,\chi)$ is Mathlib's `DirichletCharacter.LFunction χ s` (the analytic continuation of
$\sum\chi(n)n^{-s}$), $\chi^*$ is the primitive character inducing $\chi$, and $\langle\psi\rangle$ is the cyclic
group generated by a character $\psi$.

```lean
def RiemannZetaZerosOnLine : Prop :=
  ∀ s : ℂ, riemannZeta s = 0 → (¬∃ n : ℕ, s = -2 * ((n : ℂ) + 1)) → s ≠ 1 → s.re = 1 / 2
```

In ordinary mathematics:

1. `riemannHypothesis` and `riemannZeta_eq_zero_re`: every zero of $\zeta$ other than $-2,-4,-6,\dots$ has
   real part $\tfrac12$. These are the same statement; `RiemannHypothesis` is Mathlib's definition, and
   `Claim.zeta_iff : Zeta ↔ RiemannHypothesis := Iff.rfl` (`Development/AutomorphicArithmetic/CharacterBoxes/ClaimStrip.lean:102`)
   confirms that the project's wording is Mathlib's up to definitional unfolding. The excluded point $s=1$ is
   needed only because Mathlib assigns $\zeta$ a value at its pole.
2. `LFunction_ne_zero_of_half_lt_re`: for every modulus $N\ge1$, every Dirichlet character $\chi$ mod $N$
   (primitive or not, principal or not) and every $s$ with $\operatorname{Re}s>\tfrac12$, $L(s,\chi)\ne0$, except
   at the single pair ($\chi$ principal, $s=1$). This is the half-plane form of GRH for Dirichlet L-functions.
3. `LFunction_eq_zero_re`: every zero of every $L(s,\chi)$ in the open strip $0<\operatorname{Re}s<1$ has real
   part $\tfrac12$. For imprimitive $\chi$ the extra zeros from Euler factors lie on $\operatorname{Re}s=0$ and are
   outside the strip.
4. `LFunction_eq_zero_re_of_isPrimitive`: the same, for primitive $\chi$ only (implied by 3).

All five rest on one proposition, `UpperTheory.EveryCharacter`, which is statement 2 with another name
(`Development/AutomorphicArithmetic/CharacterBoxes/EveryCharacter.lean:13`, body identical to
`DirichletLNonvanishingRightOfHalf`).

### 1.2 The zero-free statement

`Formalism/SharpRestriction/RamificationFrobenius/TotientGaloisClasses/ExplicitFormulaErrorOfHostConditions.lean:11-18`:

```lean
def PChar.ZeroFreeAbove (ψ : PChar) (θ : ℝ) : Prop :=
  ∀ s : ℂ, θ < s.re → DirichletCharacter.LFunction ψ.χ s ≠ 0
```

`PChar` (`.../TotientGaloisClasses/PrimePairSizeCondition.lean:7`) is a primitive Dirichlet character packaged
with its modulus: a record $(N,\chi,\text{proof that }\chi\text{ is primitive})$. So `ZeroFreeAll` says: for every
primitive Dirichlet character $\psi$ (including the trivial character mod 1, whose L-function is $\zeta$),
$L(s,\psi)\ne0$ for $\operatorname{Re}s>\tfrac12$. `ZeroFreeOn Q` is the same restricted to the primitive
characters with property $Q$. Note that for $\psi$ trivial mod 1 the statement includes $s=1$, where Mathlib's
junk value of $\zeta(1)$ is nonzero; nothing depends on this.

## 2. Definitions unfolded

### 2.1 Characters and levels

- `Formalism.HC.PChar` (structure, `.../TotientGaloisClasses/PrimePairSizeCondition.lean:7`): a primitive
  Dirichlet character with its conductor $N$. `PChar.one` is the trivial character mod 1, `PChar.inv` the
  complex conjugate (inverse) character, `PChar.of χ` the primitive character inducing $\chi$ (Mathlib's
  `primitiveCharacter`, at level `χ.conductor`), `PChar.IsReal` means real-valued.
- `Formalism.HC.KSet` (structure, same file, line 39): a finite set `KEPT` of primitive characters containing
  `PChar.one` and closed under conjugation, together with an optional "exceptional" character `psK` which, if
  present, is in `KEPT`, odd and real.
- `Formalism.HC.Level` (structure, `ExplicitFormulaErrorOfHostConditions.lean:8`): a `KSet` plus a natural number
  `o`.
- `Formalism.HC.Level.cyc ψ` (def, same file, line 121): `Level.ofSub (Subgroup.zpowers ψ.χ)`. Unfolding
  `Level.ofSub` (line 105): `KEPT` is the set of primitive characters inducing $\psi^k$ for $k\in\mathbb Z$, `psK`
  is `none`, and `o` is the order of $\psi$. Since distinct powers of $\psi$ have distinct primitive versions,
  `KEPT` has exactly $o$ elements: $\{(\psi^k)^* : 0\le k<o\}$. This is the only kind of level that the main
  proof uses: the exceptional-character slot `psK` is always empty on the spine.

### 2.2 The smoothed prime sums

`Formalism/StatementOC.lean:11-20`:

```lean
def Sz (x : ℝ) : ℝ := ∑ n ∈ Finset.Icc 1 ⌊x⌋₊, Λ n * (x / n - 1)

def Gz (x : ℝ) : ℝ := Sz x - x * Real.log x + (1 + Real.eulerMascheroniConstant) * x
```

`.../TotientGaloisClasses/Analytic.lean:11-24`:

```lean
def logDerivativeAtOne {N : ℕ} [NeZero N] (χ : DirichletCharacter ℂ N) : ℂ :=
  deriv (DirichletCharacter.LFunction χ) 1 / DirichletCharacter.LFunction χ 1

def G (y : ℝ) : ℝ :=
  (∑ n ∈ Finset.Icc 1 ⌊y⌋₊, abelian₂ n * max (y / n - 1) 0) -
    y * (Real.log y - 1 - Real.eulerMascheroniConstant)

def sumLamChi {N : ℕ} (χ : DirichletCharacter ℂ N) (y : ℝ) : ℂ :=
  ∑ n ∈ Finset.Icc 1 ⌊y⌋₊, (abelian₂ n : ℂ) * χ (n : ZMod N) * ((max (y / n - 1) 0 : ℝ) : ℂ)

def gChi {N : ℕ} [NeZero N] (χ : DirichletCharacter ℂ N) (y : ℝ) : ℂ :=
  if χ = 1 then ((G y : ℝ) : ℂ) else sumLamChi χ y + (y : ℂ) * logDerivativeAtOne χ
```

(`abelian₂ n` is `ArithmeticFunction.vonMangoldt n`, line 9.) In formulas:
$$
G_0(y)=\sum_{n\le y}\Lambda(n)\Bigl(\frac yn-1\Bigr)-y\log y+(1+\gamma)y,\qquad
g_\chi(y)=\sum_{n\le y}\Lambda(n)\chi(n)\Bigl(\frac yn-1\Bigr)+y\,\frac{L'}{L}(1,\chi)\quad(\chi\ne1).
$$
$G_0$ is `Gz` and also `An.G` (the two agree; `GzEq.lean` in `PrimitiveCosets` proves it). Both are real-valued
for $\zeta$ and complex-valued for complex $\chi$. These are numbers depending on a real variable $y$.

`.../TotientGaloisClasses/ExplicitFormulaErrorOfHostConditions.lean:32-38`:

```lean
def Nt : Finset PChar := Λ.KEPT.erase PChar.one

def wt (ψ : PChar) : ℝ := if Λ.psK = some ψ then 1 else (3 * (Λ.o : ℝ) + 1)⁻¹

def Gm (y : ℝ) : ℝ := Formalism.Gz y + ∑ ψ ∈ Λ.Nt, Λ.wt ψ * (An.gChi ψ.χ y).re
```

For the cyclic level of a primitive $\psi$ of order $o$ (the only case used):
$$
G_m(y)=G_0(y)+\frac1{3o+1}\sum_{k=1}^{o-1}\operatorname{Re}g_{(\psi^k)^*}(y).
$$
Its prime-power part is $\sum_{n\le y}\Lambda(n)\,c(n)\,(y/n-1)$ with $c(n)=1+\frac1{3o+1}\sum_{k=1}^{o-1}
\operatorname{Re}(\psi^k)^*(n)$, and $c(n)\in(0,2)$ because the inner sum has absolute value at most $o-1$.
Positivity of $c(n)$ is never used by the proof (see 3.9); positivity of the weights $1$ and $1/(3o+1)$ is.

Comparison with the explicit formula (my computation, not stated in the code on the spine). By chapter 7,
equation `eq-rh-smoothed-formula`,
$$
G_0(X)=\log2\pi-\sum_\rho\frac{X^\rho}{\rho(\rho-1)}-\sum_{k\ge1}\frac{X^{-2k}}{2k(2k+1)} .
$$
The same contour shift for a primitive $\chi\ne1$ gives residue $-X\,\frac{L'}{L}(1,\chi)$ at $s=1$, so
$g_\chi(X)=-\sum_\rho X^\rho/(\rho(\rho-1))+O(\log X)$, the $O(\log X)$ coming from $s=0$ and the trivial
zeros. So each $g$ is exactly "the sum over zeros" of the smoothed explicit formula, with the main term removed,
and $G_m$ is a positive combination of such zero sums over the characters of $\langle\psi\rangle$. A real zero
$\beta\in(\tfrac12,1)$ contributes $-X^\beta/(\beta(\beta-1))=+X^\beta/(\beta(1-\beta))>0$: zeros to the right
of $\tfrac12$ push $G_m$ up, which is why an upper bound is the useful direction.

The note's step 5 sum, $\sum_{n\le X}\Lambda(n)(X/n-1)_+-X\log X+(1+\gamma)X$, is literally `Gz X` (the code
writes $(X/n-1)$ inside a sum over $n\le\lfloor X\rfloor$, and `max (y / n - 1) 0` in `An.G`; they agree).

### 2.4 Landau-type statements

`.../TotientGaloisClasses/Window.lean:24-33`:

```lean
def LandauWinAt (la : ℝ) : Prop :=
  ∀ θ : ℝ, 0 < θ → θ < 1 → (∃ ψ ∈ Λ.KEPT, ∃ s : ℂ, θ < s.re ∧ DirichletCharacter.LFunction ψ.χ s = 0) →
    ∃ Y0 : ℝ, ∀ Y ≥ Y0, ∃ y : ℝ, Y ≤ y ∧ y ≤ Y ^ la ∧ y ^ θ < Λ.Gm y

def LandauWin : Prop := ∀ la : ℝ, 1 < la → Λ.LandauWinAt la

def FormBAt (la : ℝ) : Prop :=
  ∀ θ : ℝ, 0 < θ → θ < 1 → HasWindows {x | Λ.Gm x ≤ x ^ θ} la → Λ.ZeroFreeAbove θ

def FormB : Prop := ∀ la : ℝ, 1 < la → Λ.FormBAt la
```

`FormBAt la` for a level $\Lambda$: for every $\theta\in(0,1)$, if $G_m(x)\le x^\theta$ on windows $[Y,Y^\lambda]$
for arbitrarily large $Y$, then every $L(s,\psi)$ with $\psi\in$ `KEPT` is nonzero for $\operatorname{Re}s>\theta$.
`LandauWinAt` is its contrapositive form (not used on the spine). `Level.ZeroFreeAbove θ` (line 24 of
`ExplicitFormulaErrorOfHostConditions.lean`) is "every $\psi\in$ `KEPT` is zero-free above $\theta$".

`FormB` is proved for every level by passing to a `Deduction.CharFamily`
(`Development/AutomorphicArithmetic/DedekindLFunctions/CharFamily.lean:24`): a finite family of Dirichlet
characters $\chi_i$, each either the trivial character mod 1 or nontrivial, with weights $a_i>0$, and
$$
G_m^F(y)=\sum_i a_i\operatorname{Re}\mathrm{Gchi}(\chi_i,y),
$$
where `Deduction.Gchi` (line 15) is $G_0$ for the trivial character mod 1 and $g_\chi$ otherwise (with the ramp
$(y/n-1)_+$ written as `max`). `level_family` (`PrimitiveCosets/LevelFamily.lean:41`) shows every level is such a
family with the same $G_m$ and the same zero-free statement (weights $1$ on `PChar.one`, `wt` on the rest).

The windowed theorem then reads, in ordinary mathematics:

> **Windowed one-sided Landau theorem** (`zeroFree_of_rpow_window`, from `lemmaL` and `windowHyp_of_rpow`).
> Let $\chi_1,\dots,\chi_r$ be Dirichlet characters, each nontrivial or the trivial character mod 1, let
> $a_i>0$, and $G_m^F=\sum a_i\operatorname{Re}\mathrm{Gchi}(\chi_i,\cdot)$. Let $0<\theta<1$, $\delta>0$, $C\in\mathbb R$.
> If for every $Y_0$ there is $Y\ge Y_0$ with $G_m^F(y)\le Cy^\theta$ for all $y\in[Y,Y^{1+\delta}]$, then
> $L(s,\chi_i)\ne0$ for all $i$ and all $\operatorname{Re}s>\theta$.

### 2.5 The Chebyshev-inequality layer (between the inputs and the analysis)

- `Formalism.MainNotions.FamCore eps` (structure, `Formalism/SharpRestriction/FamCore.lean:71`): a family of

  families for all `eps` at once.
- `Formalism.HC.EAtH Λ H TT x eps C` (structure, `ExplicitFormulaErrorOfHostConditions.lean:144`): the
  "explicit-formula error" conditions for a host `H` over a frame `φ` (a finite abelian group `φ.A` with a
  surjection onto a 2-group and a character structure; `ZsmulGeneratorEqZeroOfProjection.lean:15`) and a finite
  set `TT ⊆ φ.A`: the frame's `o` equals `Λ.o`; every kept character is realized by a frame character in `Xp`;
  the exceptional character, if any, is realized by `psC`; `TT` meets each coset of the subgroup `A0` in
  proportion `lam γ` $=(4\text{ or }3)/(3o+1)$ up to relative error $x^{-1+\varepsilon}$ (`Frame.Shares`,
  line 139); every "bounded" frame character (one not kept, or odd) induces a primitive $\chi$ with
  $|g_\chi(x)|\le x^{1/2+\varepsilon}$ (`HostRaw.BoundedCharsPointwise`, `Analytic.lean:154`); and those $\chi$
  have $|\frac{L'}{L}(1,\chi)|\le C\log x$. `EFamC Λ Fm` (`TopDefs.lean:15`): `EAtH` holds with one constant $C$
  for all data of the family at all large scales.
- `ChebyshevInequalityOnFamilyWindows Fm eD eL` (`TopWin.lean:23`): there are constants $K,c_{HH},e_K,C_L,x_0$
  such that `Tied Fm eD eL K cHH eK CL x` holds for every $x\ge x_0$ in `Fm.Win`. On the spine `Tied` is
  `ChainTied` (`Formalism/SharpRestriction/GlobalSchurBounds/TieGlobal.lean:97`), an existential over the chain
  data at scale $x$ (a base index `i0`, sizes `m f`, a `Data` record `Dd`, constants with `C.eDiv ≤ eD`,
  `C.eLoss ≤ eL`, weights `a w`, sets `TT T2`, and the size, cost and error-window conditions). Its content
  belongs to readers 2 and 3.
- `ChebyshevInequalityOnWindows Λ` (`TopWin.lean:26`):


  In words: for any family whose data satisfy the explicit-formula conditions and are "tied" on their windows,

## 3. The chain

Steps are listed from `Main` downward. "Classical" means a known theorem; "specific" means specific to this proof.

1. **`Main` from three kernel theorems.** `riemannHypothesis` and `riemannZeta_eq_zero_re` are `rhOfAll`;
   `LFunction_ne_zero_of_half_lt_re` is `allChi`; `LFunction_eq_zero_re` is `claimAll.2.1`; the primitive version is
   `critAll` (`Supplements/Kernels/MainTheorems.lean:7-16`). Each is a definitional restatement. Classical (no
   mathematics).

2. **RH from the half-plane for $\zeta$.** `Formalism.VW.rh_of_every` (`Formalism/GammaFactorNonvanishing/CritLine.lean:29`)
   specializes `EveryCharacter` to $N=1$, $\chi=1$ (Mathlib's `LFunction_modOne_eq`: $L(s,1_1)=\zeta(s)$), giving
   $\zeta(s)\ne0$ on $\operatorname{Re}s>\tfrac12$, $s\ne1$. Then `Formalism.VW.rh_of_right` (`RhOfRight.lean:5`): if
   $\zeta(s)=0$ with $\operatorname{Re}s<\tfrac12$ and $s$ not a trivial zero, Mathlib's functional equation
   `riemannZeta_one_sub` at $1-s$ writes $\zeta(s)=2(2\pi)^{-(1-s)}\Gamma(1-s)\cos(\pi(1-s)/2)\zeta(1-s)$; the
   factors are nonzero ($\Gamma$ has no zeros, the cosine vanishes only when $s\in\{0,-2,-4,\dots\}$, excluded since
   $\zeta(0)=-\tfrac12$ and the rest are trivial zeros), so $\zeta(1-s)=0$ with $\operatorname{Re}(1-s)>\tfrac12$,

3. **The strip statements.** `Formalism.VW.critLine` (`CritLine.lean:11`): for primitive $\chi$ and a zero $s$ with

   completed zeta and nonvanishing on $\operatorname{Re}s\ge1$ (Mathlib `riemannZeta_ne_zero_of_one_le_re`).
   Classical (Davenport, *Multiplicative Number Theory*, ch. 9).

9. **The windowed Landau argument.** `lemmaL` (`LandauTheorems/lemmaL.lean:13`) reduces to `landau_window`
   (`landauWindow.lean:83`), applied to $g(u)=G_m^F(e^u)$ and its Laplace transform
   $\Phi(s)=\int_0^\infty g(u)e^{-su}du=\int_1^\infty G_m^F(y)y^{-s-1}dy$. Mechanism:
   - The $k$-th Taylor coefficient of $\Phi$ at $z$ with $\operatorname{Re}z=\sigma>2$ is
     $(-1)^k\Phi^{(k)}(z)/k!=\int_0^\infty g(u)\frac{u^k}{k!}e^{-zu}du$ (`landau_coeff`, `LandauCoeff.lean:10`).
   - For given $\delta$ there are $\sigma>2$ and $C$ such that for every $U\ge1$ some $k\ge U$ makes the kernel
     $u^ke^{(2-\sigma)u}/k!$ put mass at most $C\sigma^{-k}$ outside $[U,(1+\delta)U]$ (`landau_tails`,
     `landauTails.lean:80`, a Chernoff bound). The growth $|g(u)|\le C_0e^{2u}$ is crude and is all that is needed.
   - One-sidedness enters here (`landau_window_ineq`, `landauWindowIneq.lean:27`): on the window $g\le R$ with
     $R\ge0$, hence $|g|\le 2R-g$, hence for every $\gamma$,
     $|a_k(\sigma+i\gamma)|+\operatorname{Re}a_k(\sigma)\le 2\int_{\text{window}}R\,\frac{u^k}{k!}e^{-\sigma u}du+\text{tails}$,
     and $u^ke^{-(\sigma-\theta)u}/k!\le(\sigma-\theta)^{-k}$ (`landau_kernel_max`) turns the right side into
     $\le C'e^{\eta U}(\sigma-\theta)^{-k}$ (`landau_window_key`, line 40).
   - If some zero had real part $>\theta$, then $\Phi$ has a pole closer than $\sigma-\theta$ to the line
     $\operatorname{Re}=\sigma$. `landau_dichotomy` (`LandauDichotomy.lean:24`): either the pole nearest to $\sigma$ on
     the real axis is a real $\beta>\theta$ isolated in a ball, or some point $\sigma+i\gamma$ has a unique nearest
     pole $\rho$ at distance $d<\sigma-\theta$ and a pole-free ball around $\sigma$ (`landau_nearest`). Near a simple
     pole, $a_k(z)=c/(z-\rho)^{k+1}+O(M r'^{-k})$ with $r'>d$ (`landau_pole_asym`), and Cauchy estimates bound the
     rest (`landau_cauchy`). In the complex case $|a_k(\sigma+i\gamma)|\ge|c|d^{-k-1}-Mr'^{-k}$ while
     $\operatorname{Re}a_k(\sigma)\ge-M'r'^{-k}$; in the real case $\operatorname{Re}a_k(\sigma)\ge c(\sigma-\beta)^{-k-1}-Mr'^{-k}$
     with $c>0$. Either way a term of size $d^{-k}$ is bounded by $e^{\eta U}(\sigma-\theta)^{-k}+r'^{-k}$ with
     $d<r'\le\sigma-\theta$ and $k\ge U$, which fails for $\eta$ small and $U$ large (`landau_window_contra`,
     `landau_growth_contra`).
   - Zeros with $\operatorname{Re}s\ge1$ are excluded separately (Mathlib's nonvanishing on $\operatorname{Re}s\ge1$,
     via `charFamily_LFunction_ne_zero_of_one_le_re`).

   Classical in spirit: Landau's theorem for Mellin or Laplace integrals with a one-signed integrand
   (Montgomery and Vaughan, *Multiplicative Number Theory I*, §15.1; the location should be checked by the chapter
   writer). The windowed form and the Taylor-coefficient proof are the code's; my reading is that the kernel
   $u^ke^{-\sigma u}/k!$ is the Post-Widder inversion kernel, which is what lets a window of length proportional
   to $\log Y$ suffice.

## 5. In plain terms

The last mile of the proof is a classical idea with one modern twist. The classical idea: if a smoothed count of
primes never gets much bigger than it should, then no L-function can have a zero far to the right of the critical
line. The twist: the count only has to be controlled on a sparse sequence of long stretches of scales.

Start from the function that the note singles out,
$G_0(X)=\sum_{n\le X}\Lambda(n)(X/n-1)-X\log X+(1+\gamma)X$. By the explicit formula of chapter 7 it equals
$\log2\pi-\sum_\rho X^\rho/(\rho(\rho-1))$ plus a negligible tail, so it is pure "zero noise". A zero
$\rho=\beta+i\gamma$ contributes a wave of amplitude $|X^\rho/(\rho(\rho-1))|=X^\beta/|\rho(\rho-1)|$. If all zeros have
$\beta=\tfrac12$, the noise is at most $0.0462\sqrt X$. If some zero has $\beta>\theta$, the noise has a component of size
$X^\beta$, larger than $X^\theta$.

Why only an upper bound is needed. Take the smallest example, a hypothetical real zero at $\beta=0.8$. Its term is
$-X^{0.8}/(0.8\cdot(-0.2))=+6.25X^{0.8}$: it pushes $G_0$ up, never down. So the bound $G_0(X)\le X^{0.6}$ for large
$X$ already rules it out. A complex zero $\rho=0.8+14i$ contributes, together with its conjugate, a wave
$2|X^\rho/(\rho(\rho-1))|\cos(14\log X+\phi)\approx0.0102\,X^{0.8}\cos(14\log X+\phi)$. It swings both ways, but its
positive crests come once every $2\pi/14\approx0.45$ units of $\log X$. Any upper bound of the form $G_0\le X^{0.6}$
on a stretch $[Y,Y^{3/2}]$ covers $\tfrac12\log Y$ units of $\log X$, which contains many crests once $Y$ is large,
and at a crest the wave beats $X^{0.6}$. This is why a one-sided bound suffices and why windows that are long on the
logarithmic scale suffice. With infinitely many zeros the crests could in principle conspire; the code handles that
with the Taylor coefficients of the Laplace transform of $G_0(e^u)$, which pick out the zero closest to a chosen point
and act like a smooth window at $u\approx k/\sigma$.

What the code proves, then, is: for each primitive character $\psi$ of order $o$, the combination
$G_m=G_0+\frac1{3o+1}\sum_{k=1}^{o-1}\operatorname{Re}g_{(\psi^k)^*}$ satisfies $G_m(x)\le x^{1/2+9\varepsilon}$ on
windows $[Y,Y^{3/2}]$ for arbitrarily large $Y$, for every small $\varepsilon$; hence $\zeta$ and all $L(s,\psi^k)$ are
zero-free on $\operatorname{Re}s>\tfrac12+9\varepsilon$; letting $\varepsilon\to0$, on $\operatorname{Re}s>\tfrac12$.
Mixing the characters of $\langle\psi\rangle$ with positive weights is harmless for Landau's argument, because zeros of
different L-functions add their residues with the same sign. It is needed upstream, where the upper bound is
produced through a finite abelian group in which the characters of $\langle\psi\rangle$ are the ones that are kept.

Where the upper bound comes from is outside this region, but its shape is visible. A weighted count `ASK` of
prime powers $p^i$ that are inert in an auxiliary abelian field, with the same ramp $(a/p^i-w)_+$, is compared to its
expected size `MAIN`; a finite-group explicit formula (`AskMainBalance`) says the difference is a combination of the
same smoothed sums for the characters of the auxiliary field. The chain of theta lifts shows `ASK` is not much
bigger than `MAIN`; the orthogonality of characters turns that into $G_m\le x^{1/2+9\varepsilon}$.

What fails without each hypothesis. Without windows of exponent $\lambda>1$ (that is, if the bound held only on
$[Y,2Y]$), the window would cover a bounded stretch of $\log X$ and the Taylor-coefficient argument would not
concentrate. Without the upper direction (a lower bound only), real zeros would not be excluded, since they push
upward. Without positive weights, residues of zeros of different L-functions could cancel. Among the project inputs:
without `VWin` there are no hosts (step 13), and no `HypV` for the division step; without `HypsAlt` and `Green`
there is no tied chain (`TopG`), hence no upper bound at all.
