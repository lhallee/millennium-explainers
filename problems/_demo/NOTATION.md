# Demo: notation

Internal note for writers; the page shows only what follows the first section heading.

## Numbers and counts

| Symbol | Meaning |
| --- | --- |
| $p$ | a prime number |
| $\Lambda(n)$ | von Mangoldt function: $\log p$ if $n = p^k$, and 0 otherwise |
| $\psi(x)$ | Chebyshev function $\sum_{n \le x} \Lambda(n)$ |

## Complex analysis

| Symbol | Meaning |
| --- | --- |
| $s = \sigma + it$ | the complex variable |
| $\zeta(s)$ | the Riemann zeta function |
| $\rho = \beta + i\gamma$ | a nontrivial zero of $\zeta$ |

## Colors in figures

| Meaning | Kit color name |
| --- | --- |
| the true arithmetic object | `gold` |
| the smooth estimate or main term | `blue` |
| zeros and what they contribute | `teal` |
| error, or a thing to notice | `red` |
| the critical line | `violet` |
| supporting geometry | `muted` |
